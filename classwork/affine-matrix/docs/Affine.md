# Задача 2 — двумерные аффинные преобразования

После задачи 1 реализуйте функции в `include/practice/affine.hpp`. Используйте матричные операции предыдущей задачи, прежде всего для композиции.

## Соглашения

Используем декартову систему координат: x направлен вправо, y — вверх. Точки представлены столбцами `[x, y, 1]^T`, направления — `[dx, dy, 0]^T`. Преобразование — матрица 3×3, последняя строка которой `[0, 0, 1]`. Углы измеряются в радианах, положительный поворот — против часовой стрелки.

Это аффинные, а не перспективные преобразования: деления на однородную координату здесь нет. `transform_point` и `transform_direction` принимают корректную аффинную матрицу; проверка произвольной проективной матрицы не требуется. Входные числа в обязательных тестах конечны, переполнение плавающей арифметики не входит в контракт.

## Реализуемые функции

| Функция | Значение |
|---|---|
| `translation(tx, ty)` | Перенос точки на указанный вектор |
| `scaling(sx, sy)` | Масштабирование относительно начала координат |
| `rotation(angle)` | Поворот относительно начала координат |
| `compose(after, before)` | Сначала before, затем after: результат `after * before` |
| `transform_point(matrix, point)` | Преобразование точки с w=1 |
| `transform_direction(matrix, direction)` | Преобразование направления с w=0 |

Нулевой масштаб допустим; отрицательный масштаб отражает соответствующую координату. Перенос не изменяет направление. `Point<T>` используется для обеих пар координат, а выбор функции определяет смысл.

Формулы для построения матриц:

```text
Translation       Scaling          Rotation
[1 0 tx]          [sx  0 0]         [cos(a) -sin(a) 0]
[0 1 ty]          [ 0 sy 0]         [sin(a)  cos(a) 0]
[0 0  1]          [ 0  0 1]         [  0       0   1]
```

Используйте `std::sin`, `std::cos` из `<cmath>` и `std::numbers::pi_v<T>` из `<numbers>`. Не вводите собственные тригонометрические приближения. Сравнивайте результаты с допуском, а не требуйте точного нуля от `cos(pi/2)`.

## Контрольная цепочка

Для точки `(1, 1)` выполните:

1. Масштабирование `(2, 3)` → `(2, 3)`.
2. Поворот на π/2 → `(-3, 2)`.
3. Перенос `(10, 0)` → `(7, 2)`.

Композиция записывается как `compose(translation, compose(rotation, scaling))`. Результат должен совпадать с последовательным применением. Перестановка матриц обычно меняет результат.

## Дополнительные проверки

Добавьте тесты последней строки всех построенных матриц, поворота на ноль, сохранения длины направления при повороте и некоммутативности переноса с масштабированием. Проверьте, что результирующая матрица не зависит от времени жизни локальных переменных, использованных для её построения.

## Дополнительное задание

Поворот вокруг точки pivot выразите композицией `T(pivot) * R(angle) * T(-pivot)`. Преобразуйте четыре угла прямоугольника и найдите его новый axis-aligned bounding box. Не добавляйте SIMD: цель этой практики — правильное владение, размеры и порядок преобразований.

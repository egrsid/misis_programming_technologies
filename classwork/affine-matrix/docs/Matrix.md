# Задача 1 — матричные операции без динамической памяти

Реализуйте функции в `include/practice/matrix.hpp`, заменив вызовы `todo`. Готовый `Matrix<T, Rows, Cols>` владеет `std::array`; `view()` возвращает невладеющий `std::mdspan` со статическими размерами. C++23 позволяет обращаться к элементам как `view[i, j]`.

## Контракт

| Функция | Результат |
|---|---|
| `identity<T, N>()` | Единичная матрица N×N |
| `add(a, b)` | Поэлементная сумма одинаковых по форме матриц |
| `scale(a, factor)` | Умножение каждого элемента на скаляр |
| `transpose(a)` | Матрица с переставленными строками и столбцами |
| `multiply(a, b)` | Матричное произведение M×K и K×N, результат M×N |

Работаем с `float` и `double`, без смешения типов в одной операции. Входные представления только читаются, результат владеет своей памятью. Размеры известны при компиляции. Нулевые размеры допустимы: произведение 2×0 и 0×3 даёт нулевую матрицу 2×3.

`MatrixView`, `SameShape`, `Multipliable` уже заданы как concepts. Изучите их и сохраните ограничения сигнатур. Несовместимые размеры должны отвергаться при компиляции, а не проверяться только во время выполнения. SFINAE не требуется.

Доступ к входам выполняйте через `mdspan[i, j]`: представление может иметь `layout_left`. Нельзя предполагать, что любая входная матрица хранится как `data[i * cols + j]`. Выходной Matrix всегда использует row-major layout. Динамические размеры и произвольные пользовательские accessor в обязательную часть не входят.

## Порядок выполнения

1. Посмотрите, как тест `storage` меняет массив через view и читает его через const-view.
2. Реализуйте identity, add и scale; запустите соответствующие тесты.
3. Реализуйте transpose для прямоугольных матриц.
4. Реализуйте multiply обычными вложенными циклами. Не путайте матричное произведение с поэлементным.
5. Проверьте тест `layout` и compile-time проверки в начале файла тестов.

Вычисления не должны выделять динамическую память. std::array находится внутри владельца и не обязательно на стеке: место самого владельца определяет вызывающая сторона. Не используйте `vector`, `new/delete`, AVX2, Eigen, Boost или ленивые выражения. Автоматическая векторизация обычного цикла компилятором не запрещена.

## Контрольный пример

```text
A = [1 2 3]    B = [ 7  8]
    [4 5 6]        [ 9 10]
                  [11 12]

A * B = [ 58  64]
        [139 154]
```
